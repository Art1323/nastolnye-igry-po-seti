# Настольные игры по сети

Это **готовая игра для программы 1С**. Можно играть в **шашки**, **шахматы**, **дурака** и **пасьянс** — одному, с ботом или с друзьями через общую папку на компьютере / в облаке.

Готовый файл для запуска: **[НастольныеИгрыПоСети.epf](./НастольныеИгрыПоСети.epf)**  
(нажмите на ссылку → справа кнопка **Download raw file** / «Скачать»).

---

## Что нужно заранее

1. Установленная программа **1С:Предприятие 8.3** (обычный режим работы, «управляемое приложение»).
2. Файл **`НастольныеИгрыПоСети.epf`** (скачайте из этого репозитория).
3. Если играете **с друзьями по сети** — одна **общая папка**, к которой есть доступ у всех игроков (см. раздел «Как сделать общую папку»).

Не нужно уметь программировать. Достаточно уметь открывать файлы и вводить текст в поля.

---

## Как открыть игру в 1С (пошагово)

1. Скачайте файл `НастольныеИгрыПоСети.epf` на компьютер (например, на **Рабочий стол**).
2. Запустите **1С:Предприятие** и откройте свою базу (как обычно).
3. В меню выберите: **Файл → Открыть…**
4. Найдите скачанный файл `НастольныеИгрыПоСети.epf` и откройте его.
5. Откроется окно: **«Настольные игры по сети»**.

Если пункта «Файл → Открыть» нет — спросите у администратора 1С, как подключить внешнюю обработку. Часто можно добавить обработку в список внешних обработок справочника.

## Что вы видите на экране

Вверху — кнопки:

| Кнопка | Зачем |
|--------|--------|
| **Создать игру** | Вы создаёте партию. Другие подключаются к вам. Вы — «хост». |
| **Подключиться** | Вы заходите в уже созданную партию. |
| **Локально** | Игра вдвоём за **одним** компьютером (передаёте мышку). |
| **С ботом** | Играете против компьютера. |
| **Обновить** | Обновить доску / статус (на всякий случай). |
| **Сдаться** | Сдаться в текущей партии. |
| **Начать матч** | Только для **Дурака** и только у хоста: начать раздачу карт, когда в лобби уже есть игроки. |
| **Переподключиться** | Вернуться в уже идущую партию (по коду, паролю и имени / PlayerID). |
| **Комнаты** | Список активных комнат в общей папке. |
| **Очистить** | Удалить старые/завершённые файлы партий. |

Ниже — настройки:

| Поле | Что писать |
|------|------------|
| **Игра** | Шашки / Шахматы / Дурак / Пасьянс |
| **Общая папка** | Путь к папке, общей для всех игроков (кнопка **Папка…** поможет выбрать) |
| **Ваше имя** | Как вас будут видеть другие (например: `Анна`, `Игрок1`) |
| **Код партии** | Одно и то же слово/код у всех (например: `party1`). Это «номер комнаты». |
| **Пароль** | Необязательно. Если хост задал пароль — гости вводят тот же. |
| **Колода** / **Переводной** | Только для Дурака |

Блок **Комнаты и чат**: список комнат и сообщения комнаты (кнопка **Чат**).

Строки **Статус** и **Ход** показывают, что происходит сейчас (ожидание, чей ход, таймер и т.д.).

Для разработчиков: [docs/ARCHITECTURE.md](./docs/ARCHITECTURE.md), таблица правил [docs/RULES_CHECKLIST.md](./docs/RULES_CHECKLIST.md), smoke-тесты [tests/](./tests/).

## Режимы: что выбрать

### 1) Один за компьютером — с ботом

1. Выберите игру (Шашки / Шахматы / Дурак).
2. Нажмите **С ботом**.
3. Играйте кнопками / кликами по доске или картам.

Пасьянс бота не использует — просто выберите **Пасьянс** в списке игр.

### 2) Вдвоём за одним компьютером

1. Выберите игру.
2. Нажмите **Локально**.
3. Ходите по очереди (ход переключается сам).

### 3) С друзьями по сети (разные компьютеры)

Нужна **одна и та же общая папка** и **один и тот же код партии**.  
Подробно — ниже.

## Как сделать общую папку (простыми словами)

Общая папка — это место, куда 1С у каждого игрока пишет файлы партии. Все должны видеть **одну и ту же** папку.

### Вариант А. Компьютеры в одной сети (дом / офис)

1. На одном ПК создайте папку, например: `C:\Игры1С\Общая`.
2. Откройте к ней **общий доступ** (ПКМ по папке → «Свойства» → «Доступ» → дать чтение и запись другим).
3. У остальных в проводнике откройте эту папку по сети, например: `\\ИМЯ-ПК\Игры1С\Общая`.
4. В обработке в поле **Общая папка** укажите этот путь (у хоста может быть `C:\…`, у гостей — `\\ИМЯ-ПК\…` — главное, чтобы это была **одна** папка).

### Вариант Б. Яндекс.Диск / облако

1. Установите приложение облака на все компьютеры.
2. Создайте папку, например: `Яндекс.Диск\Игры1С`.
3. Дождитесь синхронизации на всех ПК.
4. В поле **Общая папка** укажите путь к этой папке на своём компьютере  
   (например: `C:\Users\ВашеИмя\YandexDisk\Игры1С`).

Важно: в облаке файлы появляются не мгновенно (иногда 2–10 секунд). Не жмите кнопки слишком часто подряд — подождите немного.

## Игра по сети: пошагово

### Шаг 1. Договоритесь

- Какую игру играете.
- Какой **код партии** (например `party1`) — **одинаковый у всех**.
- Какая **общая папка**.
- Кто будет **хостом** (создаёт игру). Остальные — гости.

### Шаг 2. Хост создаёт партию

1. Откройте обработку в 1С.
2. Выберите **Игру**.
3. Укажите **Общую папку**.
4. Введите **Ваше имя**.
5. Введите **Код партии**.
6. Для Дурака выберите колоду (36/52) и при желании галочку **Переводной**.
7. Нажмите **Создать игру**.

Хост ждёт, пока подключатся остальные.

### Шаг 3. Гости подключаются

1. Откройте **ту же** обработку на своём ПК.
2. Выберите **ту же игру**.
3. Укажите **ту же общую папку** и **тот же код**.
4. Введите **своё имя** (не такое же, как у другого игрока).
5. Нажмите **Подключиться**.
6. Если это Дурак — прочитайте правила и нажмите **Да**.

### Шаг 4. Старт

- **Шашки / шахматы** — игра часто начинается сразу после подключения второго игрока.
- **Дурак** — все видят **лобби** (список имён). Хост, когда готов, жмёт **Начать матч** (можно не ждать всех 4 человек, достаточно хотя бы одного соперника).

---

## Дурак — важные правила этой обработки

- На ход даётся **120 секунд**. Если не успели сделать ход — **проигрыш по времени**.
- Можно **сдаться**. Если игроков 3–4, остальные **продолжают** без вас.
- Если кто-то просто закрыл 1С / обработку — остальные тоже могут продолжить; на экране будет сообщение, что игрок отключился.
- После конца партии можно вернуться в **лобби** и начать новый матч.

Как ходить: кликайте по своим картам и по слотам на столе / кнопкам **Бито**, **Взять**, **Перевод** (если включён переводной).

---

## Шашки и шахматы

- Кликайте по клетке со своей фигурой, затем по клетке хода.
- Можно вводить клетки текстом (если поля видны) — например `a3` и `b4`.
- В шашках есть настройка **Обязательное взятие**.

---

## Пасьянс

1. Выберите игру **Пасьянс**.
2. Партия начнётся сразу (сеть не нужна).
3. Кликайте по стоку, картам и домам. Есть **Ход назад**.

## Частые проблемы

**«Файл партии не найден»**  
Проверьте: одинаковые **общая папка** и **код партии**; хост уже нажал **Создать игру**; папка реально доступна на запись.

**Гость не видит партию**  
Подождите 5–15 секунд (особенно в облаке) и нажмите **Обновить**. Убедитесь, что выбрана та же игра (Дурак / Шашки / Шахматы).

**«Игрок с таким именем уже в лобби»**  
Смените **Ваше имя**.

**Ничего не происходит / ход не ваш**  
Смотрите строку **Ход** и **таймер**. Ходите только когда написано, что ход ваш.

**Игра сразу закончилась «отключился»**  
Чаще всего общая папка плохо синхронизируется. Лучше общая папка в локальной сети, чем медленное облако. Не закрывайте окно обработки во время партии.

**Не открывается `.epf`**  
Нужна платформа 1С 8.3. Открывайте через **Файл → Открыть** внутри 1С, а не двойным щелчком из проводника (двойной щелчок тоже иногда работает, если ассоциации настроены).

## Для тех, кто собирает из исходников (не обязательно)

Если вы правите код:

1. В конфигураторе загрузите обработку из файлов (`НастольныеИгрыПоСети.xml`).
2. Сохраните как `НастольныеИгрыПоСети.epf`.

Обычным игрокам это **не нужно** — используйте готовый `.epf` из репозитория.
