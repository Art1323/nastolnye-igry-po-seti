# Настольные игры по сети

Внешняя обработка **1С:Предприятие 8.3** (управляемые формы): **шашки**, **шахматы**, **дурак**, **пасьянс**.  
Игра локально, с ботом или **по сети через общую папку** (JSON-файлы).

Готовый файл: [`НастольныеИгрыПоСети.epf`](./НастольныеИгрыПоСети.epf)

## Быстрый старт

1. Скачайте `НастольныеИгрыПоСети.epf` из этого репозитория.
2. В 1С: **Файл → Открыть** → выберите `.epf` (или подключите как внешнюю обработку).
3. Для сети укажите **общую папку** (доступна всем игрокам) и **код партии**.

## Возможности

| Игра | Игроки | Сеть | Бот | Локально |
|------|--------|------|-----|----------|
| Шашки | 2 | да | да | да |
| Шахматы | 2 | да | да | да |
| Дурак | 2–4 | да | да (2) | да (2) |
| Пасьянс «Косынка» | 1 | нет | нет | да |

### Дурак (сеть)

- Колода **36** или **52**, опционально **переводной**
- **Лобби**: имена игроков, хост жмёт **«Начать матч»** (можно не ждать всех четверых)
- При подключении гость видит правила хоста
- Анимация раздачи
- **Таймер хода 120 с** — не успел сделать ход → проигрыш по времени
- Сдача / закрытие 1С: при 3–4 игроках партия **продолжается** с оставшимися; остальным показывается сообщение
- После конца матча можно вернуться в **лобби**

### Шашки / шахматы

- HTML-доска, ход кликом
- Шашки: обязательное взятие (настройка), дамки, цепочки
- Шахматы: шах/мат/пат, рокировка, взятие на проходе, превращение в ферзя

### Пасьянс

- Классическая «Косынка», ход назад

## Сеть

1. **Хост**: имя → общая папка → код → настройки (для дурака) → **Создать игру**.
2. **Гости**: та же папка и код → **Подключиться**.
3. Дурак: гости ждут в лобби → хост **Начать матч**.

Файлы партии в общей папке:

- `durak_<код>.json`
- `shashki_<код>.json`
- `chess_<код>.json`
- пульсы сети: `durak_<код>_hb_0.txt` … `_hb_3.txt`

## Сборка из исходников

Исходники — выгрузка внешней обработки в XML + `.bsl`.

1. Конфигуратор 1С → открыть / создать внешнюю обработку.
2. Загрузить из файлов → корень `НастольныеИгрыПоСети.xml`.
3. Сохранить как `НастольныеИгрыПоСети.epf`.

Основные модули:

- `НастольныеИгрыПоСети.ObjectModule.txt` / `…\Ext\ObjectModule.bsl` — логика игр
- `НастольныеИгрыПоСети.Form.Форма.Form.Module.txt` / `…\Forms\Форма\Ext\Form\Module.bsl` — форма и сеть

## Требования
