# Таблица правил и покрытие тестами

Легенда: **A** — автотест в `tests/`, **M** — ручная проверка в 1С, **C** — покрыто кодом генерации ходов.

## Шашки

| Правило | Статус |
|---------|--------|
| Ход только по тёмным клеткам | C |
| Простая ходит вперёд по диагонали | C / A smoke |
| Дамка ходит в любом направлении | C |
| Взятие обязательное (если включено) | C / M |
| Цепочка взятий | C / M |
| Превращение в дамку | C |
| Победа: нет фигур / нет ходов | C |

## Шахматы

| Правило | Статус |

| Шах / мат / пат | C |
| Рокировка | C / M |

| Превращение пешки | C / M |
